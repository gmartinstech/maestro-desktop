# ViewCard

A generated app or output card — what an agent hands back when it builds something. Its
defining feature is the 4-way segmented pill in the header: Preview / Code / Terminal /
History. `interactive` shows the accent halo used while the user has clicked into the live
app (Escape returns to canvas navigation).

```tsx
<ViewCard x={560} y={520} width={640} height={360} title="Release notes preview" instanceLabel="#1" />
```

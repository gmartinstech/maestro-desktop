# NoteCard

A sticky note on the canvas. The one card that is paper, not surface: a fixed pastel
palette (`color`) that stays the same in light and dark mode, a chromeless 18px header,
and controls that only appear on hover. Never uses the theme's surface/border tokens.

```tsx
<NoteCard x={1240} y={120} color="yellow" text="Ping Gabriel once the signature check is verified." />
```

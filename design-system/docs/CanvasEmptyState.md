# CanvasEmptyState

The dashboard canvas's first-run state: "What do you want done?" over a four-category
starter picker (Research, Build an app, Use the web, Connect your apps). Renders inside the
canvas surface in place of cards; `DashboardScreen`'s `empty` prop shows it in context.

```tsx
<CanvasEmptyState />
```
